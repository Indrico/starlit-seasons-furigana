# v0.2.0-alpha.1 functional development candidate

This is a local verification candidate, not a published GitHub release.
The public v0.2 prerelease remains pending performance work and remaining checks.
The published v0.1.0-alpha.2 package is unchanged.

- Manual dialogue by default; F6 switches and saves manual/automatic progression.
- Complete text and furigana are prepared together through a build-locked native
  bridge. Ordinary dialogue keeps fixed 29/14 sizes and paginates overflow.
- Compact dialogue follows the original panel width, with closer ruby and
  mirrored native window textures. Font size does not change with line length.
- OPTION contains the persistent master On/Off switch for all mod features;
  F8 works while that menu is open. F7 remains the furigana-only shortcut.
- Enabled startup skips the native logo flow to Press Any Button.
- The ZIP bundles the compiled bridge, pinned UE4SS loader, annotation-only
  data, and UE4SS/MinHook licenses. Players need no build or extraction tools.

See [English controls and preferences](../dialogue-controls.md) and
[verification evidence and limitations](../runtime.md).

The local candidate ZIP has 21 runtime files and five helper files, totaling
11,785,701 bytes. SHA-256:

or complete-game compatibility is claimed for this candidate.
