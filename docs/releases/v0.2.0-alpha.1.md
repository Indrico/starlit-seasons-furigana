**Drag-and-drop Windows prerelease** for THE IDOLM@STER STARLIT SEASON 1.61 /
Steam build `8278842`. No build tools or Python are required.

### Download and install

Download **`starlit-season-furigana-v0.2.0-alpha.1-windows-x64.zip`** from this
release, rather than GitHub's automatic Source code archives.

1. Close the game. If upgrading, run the old **Uninstall-Furigana.cmd first**.
2. In Steam, open **Properties → Installed Files → Browse**.
3. Extract **all ZIP contents** beside **StarlitSeason.exe**.
4. Run **Check-Furigana.cmd**, then launch normally through **Steam**.

The checker validates the supported executable and runtime files. When present,
the known English patch is backed up and disabled so the original Japanese
dialogue can be annotated. **Uninstall-Furigana.cmd** restores those backups
and preserves your preferences. Existing third-party loaders must be managed
separately; the checker does not merge them.

### Changes since v0.1.0-alpha.2

- Dialogue is manual by default. **F6** switches manual/automatic advancement;
  the choice persists. Voice and character animation continue while held.
- Complete text and furigana are prepared together at native line assignment.
  Fixed font sizes, compact native-width windows, closer ruby, and pagination
  replace delayed resizing on the supported native path.
- **F7** toggles furigana independently. **OPTION → Furigana Mod** toggles all
  mod features; **F8** is its keyboard equivalent while Options is open.
- Enabled startup skips the opening logos to **Press Any Button**.
- Repeated global object scans are replaced by an initial snapshot and queued
  construction notifications. Game-thread timers, bounded width caches, and
  lazy ruby widget allocation reduce recurring work and callback churn.

The local 1920 × 1080 held-dialogue comparison reduced p99 frame intervals from
**59.715–60.119 ms to 6.849–6.858 ms** across three 120-second runs per build.
Frames above 50 ms fell from 469–471 per run to zero. A separate automatic
dialogue capture showed the same removal of recurring spikes. These results
describe one machine and sampled scene, not a guaranteed frame rate.
See the [performance report](https://github.com/Indrico/starlit-seasons-furigana/blob/v0.2.0-alpha.1/docs/performance.md).
