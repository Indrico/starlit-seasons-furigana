# v0.3.0-alpha.3 - Pause furigana work during MV/live

MV/live performances now suspend furigana discovery and preparation automatically.
Previously, menu/name/log checks continued while a performance was playing.
The mod now tracks the game's performance manager, restores existing overlays
once, and skips text discovery, lookup, geometry, measurement, and rendering work
until that manager expires. Native performance controls and text remain usable.
Master, F7, and manual/automatic preferences are preserved.

This release also reduces delayed menu/name/log readings: ready native text
assignments can prepare their overlays before returning; font metrics are shared
in a bounded cache; plain labels need fewer measurements; and compatible plain
backlog runs share widgets. Native UI font sizes and widths stay unchanged.
New screens still need valid native geometry, so this does not guarantee that
every reading is present on its first frame. Native text remains visible while
cold preparation finishes.

## Installation

Download `starlit-season-furigana-v0.3.0-alpha.3-windows-x64.zip`.
Close the game and uninstall the previous managed version. Extract all contents
next to `StarlitSeason.exe`, run `Check-Furigana.cmd`, then launch through Steam.
No build tools, Python, or separate loader download are needed. Preferences
survive uninstalling and upgrading. See the [English usage guide](../usage.md).

- **F6:** manual/automatic dialogue.
- **F7:** furigana off/on.
- **OPTION > Furigana Mod: ON/OFF**, or **F8** there: every mod feature.
- **MV/live suspension:** automatic; no new shortcut or configuration required.

The supported target remains Windows x64, game 1.61 / Steam build 8278842.

## Verification and limits

The source suites contain 147 tests, including performance entry/exit, cached
manager detection, suspension without scanning/preparing UI, preference
preservation, shared metrics, native kerning, and cooperative work scheduling.
See [runtime verification](../runtime.md) and [performance evidence](../performance.md)
for native checks, measurements, and their limits.

The loader, native bridge, tiny timer callbacks, and queued object notifications
remain loaded during suspension. This removes furigana preparation from the
performance; it does not establish that all frame drops came from this mod or
promise stutter-free playback. The exploratory suspended MV capture still had
frame spikes and a worse p99 than an unsynchronized pre-suspension capture;
an overall FPS improvement has not been established. Automatic reading errors, unsupported labels,
and untested scenes/controller paths remain alpha limitations.
