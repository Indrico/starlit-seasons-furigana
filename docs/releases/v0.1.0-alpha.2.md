**Drag-and-drop Windows release** for THE IDOLM@STER STARLIT SEASON 1.61 /
Steam build `8278842`.

### Download and install

Download **`starlit-season-furigana-v0.1.0-alpha.2-windows-x64.zip`** below.
Choose this asset rather than GitHub's automatic Source code archives.

1. Close the game.
2. In Steam, open **Properties → Installed Files → Browse**.
3. Extract **all ZIP contents** into that folder, next to **StarlitSeason.exe**.
4. Double-click **Check-Furigana.cmd** once.
5. Launch normally through **Steam**. Use Japanese dialogue; **F7** toggles furigana.

**No Python, compilation, extraction tools, or separate downloads are needed.**
The pinned UE4SS loader and prebuilt annotations are included. `SHA256SUMS.txt`
contains the package checksum.

### Included

- Furigana annotations for **49,749 distinct source strings** with readings.
- The tested UE4SS loader, settings, and native signatures, with the loader's MIT license.
- A Windows checker and uninstaller. The checker validates the build and package
  files and backs up/disables the known English patch when present.
- `Uninstall-Furigana.cmd` restores patch backups and preserves unrelated files.
- An English quick-start README inside the ZIP.

Original game dialogue and resource keys are excluded. Prebuilt data contains
source hashes, positions, and kana; the mod reads base text from the game's
current widget. Original executables and base PAKs remain intact.

For existing mod installations, uninstall or preserve the old loader **before**
copying this ZIP. This package targets a fresh game runtime and does not merge
third-party loaders. See the [English usage guide](https://github.com/Indrico/starlit-seasons-furigana/blob/v0.1.0-alpha.2/docs/usage.md).

### Validation and limits

60 source tests passed, including Windows helper round trips and locked-file
rollback. The release lookup was compared against all **53,567 distinct source
strings** in the local corpus; all reading spans and control markers matched.
The exact ZIP also passed a clean runtime installation, Steam launch, visible
furigana and F7 checks, removal with both patch files restored, and reinstallation.

Readings remain automatic and may be wrong. Menus, profiles, and lyrics are out
of scope. Normal-play choice input, controllers, true 1080p, and a full
playthrough remain unverified. See the [verification record](https://github.com/Indrico/starlit-seasons-furigana/blob/v0.1.0-alpha.2/docs/runtime.md).
