First public alpha of **Starlit Season Furigana** for game 1.61 / Steam build
`8278842` (Unreal Engine 4.24).

### Download

Download **`starlit-season-furigana-v0.1.0-alpha.1-source.zip`** from the assets
below and extract it outside the game folder. `SHA256SUMS.txt` contains the
package checksum.

This is a **source and local-build package**, not a drag-and-drop binary mod.
It includes the renderer, installer, extraction and reading tools, tests, and
English documentation. Generate readings from your own installed game and
download the pinned UE4SS loader separately. Game archives, original dialogue,
generated reading tables, resource keys, saves, and memory dumps are excluded.

### How to use

**Already installed:** launch the game normally through Steam. Furigana starts
enabled; press **F7** to turn it off or on. Readings appear above kanji after a
complete matching dialogue line finishes revealing and stays stable for 250 ms.

**First installation:** follow the included English guide:
[Download, setup, play, and uninstall](https://github.com/Indrico/starlit-seasons-furigana/blob/v0.1.0-alpha.1/docs/usage.md).
It covers Python setup, local text extraction, reading generation, the pinned
loader download, installation, and removal.

### Included behavior

- Kana above annotated kanji in Japanese conversation text and answer labels.
- Original game font, automatic font fitting, and native typewriter reveal.
- F7 toggle with native text restoration.
- Installer with exact build/loader checks, English-patch backup, and removal.
- Original executables and base PAK archives remain intact.

### Validation and limits

46 source tests passed. Local visual checks observed ordinary dialogue, fitted
two-line text, three answer labels, and the F7 toggle at 1680 by 1050. Real
installation/removal restored both English-patch files with identical hashes.

Readings are automatic and may be wrong; candidate coverage is not an accuracy
score. Menus, profiles, and lyrics are outside this release's scope. Unsupported
text/layouts keep native rendering. Interactive choices in normal play,
controller input, true 1080p rendering, and a complete playthrough remain
unverified. See the [verification record](https://github.com/Indrico/starlit-seasons-furigana/blob/v0.1.0-alpha.1/docs/runtime.md).
